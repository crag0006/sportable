### 0.4 Decisions

1. **Links are whitelisted by the answer builder, not trusted from the model.** Every `href` in the response must be one the tool results carried; anything else is dropped. The prompt now also says so (rule 9), but the builder is the guarantee. This goes into contract v0.3 section 8.
2. **Scope wording for Haiku**: "programs" must be defined as anything the publisher lists (playgrounds, arts, social groups included), and the instruction becomes "when unsure, search first; refuse only when nothing is found". Haiku follows the scope sentence literally; Qwen was more willing to look.
3. **Haiku is the production model**: four times faster, 72-word answers against 85, same grounding. The two Haiku failures are prompt and builder fixes, not model limits.
4. **Tool mode stays the recommendation.** Passive mode matched tool mode on Qwen (24 / 25 each) with fewer rounds, but it embeds every message and injects passages on venue questions; nothing in the results argues for paying that on every turn.
5. **Not re-run after these changes**, by agreement, to save the Haiku budget. The next Haiku run should be made after the prompt and builder changes land, with the same 25 cases, and is expected to be 25 / 25.
